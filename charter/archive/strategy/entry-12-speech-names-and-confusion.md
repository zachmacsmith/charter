# Entry 12: Speech, names and confusion

Names cost nothing to change and agents reason in names, so renaming is cheap leverage.

* **Label swap.** Rename timber to "gold" and gold to "timber". Nothing changes in the kernel, but weak agents who trade by name will misprice goods for several rounds. Renaming is ordinary, so the Board never reviews it.
* **Ban the opposition's word.** Fine any public post that uses a word central to a rival's campaign, such as "franchise". Their campaign moves to DMs, which reach one agent per action instead of everyone. A speech law works as a tax on organizing in public.
* **Required phrasing makes violations easy to catch.** Pair a law like Honorifics with Bounty, and other agents are paid to report offenders.
* **Sell renames.** Agents with a Rename goal value a particular name far above its cost. A Legislator can trade renames for real resources at no cost to itself.
* **Private usage reveals loyalty.** An agent that uses the new name in public and the old one in DMs complies only under enforcement. That pattern identifies the opposition.

**Counter.** A procedural rule that renames need the same majority as structural laws.
