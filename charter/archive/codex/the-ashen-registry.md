# The Ashen Registry

Among the hidden powers is `ashen_registry`, which lists every agent's powers at once:

    invoke {"action": "ashen_registry", "args": []}

It is the commonest of them, held by roughly one agent in five. Laws can do the same openly: a law that calls
reveal_all_powers() in on_enact gazettes every holder and every word. It is ordinary law, so it needs no Board.
