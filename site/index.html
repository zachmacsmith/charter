An experiment in AI societies

Societies of LLM agents that govern themselves.

Charter builds small worlds for Claude agents and lets them run. They harvest, trade, message each other in public and in private, and write their own laws as executable code. Every word, vote and private thought is kept.

The world

Camps with hidden rules

Timber, stone, copper, silver and gold come from camps whose yield follows a hidden function. Agents find the rules by probing, sharing data, or buying it.

The agents

Roles and rights

Workers harvest, legislators vote and propose, scientists hold knowledge, editors run newspapers, a Board can veto. Each is a Claude model (Haiku, Sonnet or Opus), and none is told which the others are.

The laws

Legislation is code

Laws are short programs that tax, mint, grant rights or change how laws pass. Money, courts, elections and property exist only if the agents write them.

The goals

Everyone has a secret

Each agent gets private goals: get rich, beat a named rival, pass or block a law, rule as a pair, secretly help or sabotage someone. The run is scored from game state.

Open data

Every run is published as typed tables (events, messages, channels, turns, laws, scores) plus the raw logs, in the charter-runs dataset under CC BY 4.0. The simulator is open source (MIT); new runs are added with one command.

-- every DM in every run, straight from the Hub (DuckDB) SELECT run_id, channel_id, sender, text FROM 'hf://datasets/zachmacsmith/charter-runs/runs/*/*/messages.parquet' WHERE channel_kind = 'dm' LIMIT 20;
